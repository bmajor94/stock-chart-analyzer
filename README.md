# 차트 지표 분석 대시보드

미국 주식 OHLCV를 받아 기술적 지표를 계산하고 캔들차트에 겹쳐 보여주는 Streamlit 앱.

## 실행

**`차트분석 실행.command` 를 더블클릭한다.** 터미널 창이 하나 열리고 브라우저가 자동으로 뜬다. 끄려면 그 창을 닫는다.

- 이미 켜진 상태에서 다시 눌러도 안전하다 — 서버를 새로 띄우지 않고 브라우저만 연다.
- 처음 실행이거나 `.venv`가 없으면 알아서 환경을 만들고 패키지를 설치한다 (몇 분 소요).
- 자주 쓰면 이 파일을 Dock 오른쪽(휴지통 옆 구역)에 끌어다 놓거나, `⌘⌥` 누른 채 바탕화면으로 끌어 별칭을 만든다.

터미널에서 직접 띄우려면:

```bash
.venv/bin/streamlit run app.py
```

앱이 켜져 있는 동안에는 같은 와이파이의 폰·태블릿에서도 터미널 창에 찍힌 **Network URL** 로 접속된다.

### 런처가 headless 로 띄우는 이유

그냥 `streamlit run` 하면 첫 실행 때 이메일을 물어보며 입력 대기 상태로 멈춘다. 더블클릭 실행에서는 그게 그대로 먹통으로 보이므로, `--server.headless true` 로 띄우고 브라우저는 스크립트가 `open` 으로 직접 연다.

## 구성

| 파일 | 역할 |
|---|---|
| `app.py` | Streamlit UI — 사이드바 설정, 헤더 지표, 해설, 차트, 신호 목록, CSV 내려받기 |
| `data.py` | yfinance 조회. MultiIndex 컬럼을 펴고, 시간외 구간을 표시하고, 티커 오류를 사람이 읽을 메시지로 바꾼다 |
| `indicators.py` | 지표 계산. pandas만 사용하며 TA-Lib 등 외부 의존성이 없다 |
| `tickers.py` | 우량주 80종목 목록(한글명 포함)과 Yahoo 종목 검색 |
| `score.py` | 8개 조건을 긍정/부정으로 집계한 종합 판독 |
| `signals.py` | 관례적 조건(교차·돌파)이 충족된 시점 탐지 |
| `explain.py` | 지표 숫자를 평이한 한국어 문장으로 옮김 |
| `chart.py` | Plotly 서브플롯 조립 |
| `theme.py` | 라이트/다크 각각 따로 고른 색 팔레트 |

## 지표

- **이동평균** — SMA 20/50/200, EMA 12/26
- **볼린저 밴드** — 중심선·상단·하단, 밴드폭, %B
- **RSI** — Wilder 평활 방식, 기본 14
- **MACD** — 12/26/9, 히스토그램 포함
- **거래량** — 종가 방향별 색 구분 + 거래량 이동평균

모든 기간 파라미터는 사이드바 '파라미터 조정'에서 바꿀 수 있다.

## 종목 고르기

두 가지 방법이 있다.

- **우량주 목록** — 미국 대형주·ETF 80종목. 셀렉트박스를 열고 그냥 타이핑하면 걸러진다. 라벨이 `NVDA · 엔비디아 · 반도체` 형태라 티커(`nv`)·한글명(`엔비`)·분류(`반도체`) 아무거나로 찾힌다.
- **직접 검색** — Yahoo 검색에 그대로 넘긴다. 목록에 없는 종목용.

**Yahoo 검색은 한글 질의를 못 알아듣는다** (`엔비디아` → 0건). 그래서 자주 쓰는 종목은 `tickers.py`에 한글명을 붙여 들고 있고, 직접 검색은 영문명·티커만 받는다. 목록에 종목을 추가하려면 `BLUE_CHIPS`에 `(티커, 한글명, 분류)` 한 줄을 넣으면 된다.

한글명에 이미 들어 있는 말은 `ALIASES`에 넣지 않는다 — 라벨에 두 번 찍힌다.

## 종합 판독

8개 조건을 각각 긍정/부정으로 판정해 집계하고, 다수 쪽을 🟢 긍정 / 🔴 부정으로 표시한다. 4:4로 갈리면 ⚪ 중립이다.

| 조건 | 긍정 판정 기준 |
|---|---|
| 단기·중기·장기 추세 | 종가가 SMA20 / SMA50 / SMA200 위 |
| 이동평균 배열 | SMA20이 SMA50 위 (정배열) |
| MACD 교차 상태 | 히스토그램 ≥ 0 |
| MACD 0선 | MACD ≥ 0 |
| RSI 방향 | RSI ≥ 50 |
| 볼린저 위치 | %B ≥ 0.5 |

집계만으로는 오해가 생기는 상황에는 경고가 따로 붙는다.

- **RSI 70 이상 / 30 이하** — 조건이 한쪽으로 몰리는 건 이미 크게 움직였기 때문이지 계속 간다는 뜻이 아니다.
- **쏠림 65% 미만** — 조건이 팽팽해 판독 신뢰도가 낮다.
- **판정된 조건이 절반 미만** — 조회 기간이 짧아 지표가 덜 만들어졌다. 강도를 '근거 부족'으로 표시한다.

**이 판독은 매수·매도 권유가 아니다.** 지표는 이미 일어난 가격 움직임을 요약할 뿐이라 '긍정'은 최근 많이 올랐다는 뜻이지 더 오른다는 뜻이 아니다.

## 해설과 신호

차트를 읽을 줄 몰라도 현재 상태를 파악할 수 있도록 두 가지가 붙어 있다.

- **지표 해설** — 추세·과열도·변동성·모멘텀·거래량 다섯 항목을 평이한 문장으로 옮긴다. 전부 '지금 값이 어디에 있는지'에 대한 사실 서술이다.
- **신호 표시** — 아래 조건이 충족된 봉에 마커를 찍고, 최근 10건을 표로 보여준다. 조건이 발생한 패널에 그린다.

| 조건 | 패널 |
|---|---|
| 골든크로스 / 데드크로스 (SMA20 × SMA50) | 가격 |
| RSI 70 상향 돌파 / 30 하향 돌파 | RSI |
| MACD 상향 / 하향 교차 | MACD |

**이건 매수·매도 권유가 아니다.** 널리 쓰이는 조건이 언제 충족됐는지를 표시할 뿐이고, 맞을 때도 틀릴 때도 있다. 실제 결과를 보면 데드크로스 다음 날 골든크로스가 나는 식으로 하루 만에 뒤집히는 경우도 섞여 있다.

## 차트 규칙

- 스케일이 다른 지표를 한 축에 겹치지 않는다. 가격·거래량·RSI·MACD가 각각 독립된 행이고 x축만 공유한다.
- 조회 기간이 지표 기간보다 짧아 값이 전부 비는 이동평균은 범례에서 자동으로 빠진다.
- 일봉일 때만 주말 공백을 접는다. 주봉·월봉에 적용하면 주말에 걸린 봉이 사라진다.
- 라이트/다크 팔레트를 각각 따로 정의했다. 사이드바에서 '자동'(스트림릿 테마 추종)·'라이트'·'다크' 중 고른다.
- 인트라데이는 밤 시간대를 접고, 일봉은 주말만 접는다. 접지 않으면 캔들이 뭉치고 이동평균이 계단처럼 꺾여 보인다.
- `rangebreaks`를 걸면 plotly의 자동 x축 범위가 뒤쪽을 잘라먹으므로 범위를 명시한다.

## 시간외 거래

- **일봉 이상에서는 볼 수 없다.** Yahoo가 일봉에서는 `prepost` 옵션을 무시하므로 정규장(09:30~16:00 ET) 집계만 돌아온다. 장 마감 후 시간외 움직임은 다음 날 봉에 반영된다.
- **분봉·시간봉에서 사이드바 '시간외 거래 포함'을 켜면** 프리마켓(04:00~) · 애프터마켓(~20:00) 봉까지 받는다. 해당 구간은 차트에 옅은 세로 띠로 표시된다.
- 시간외는 거래량이 얇아 가격이 튀기 쉽다. 같은 지표라도 정규장만 볼 때와 값이 달라진다.

## 데이터

Yahoo Finance(yfinance)에서 조정 종가 기준으로 받아온다. 조회 결과는 60초간 캐시되며 사이드바의 '데이터 새로고침'으로 즉시 비운다.

봉 주기별 조회 가능 기간은 Yahoo 쪽 제약을 따른다 (`app.py`의 `PERIODS`). 분봉은 최근 며칠까지만 조회된다.

## 범위

이 앱은 지표를 계산하고, 그 값이 지금 어디에 있는지 설명하고, 관례적 조건이 충족된 시점을 표시한다.

백테스트(과거 수익률·승률·최대낙폭 계산)는 들어 있지 않다.

**투자 자문이 아니다.** 어떤 종목을 사야 하는지, 지금이 살 때인지에 대한 판단은 담고 있지 않고 담을 수도 없다.
